# ใบแจ้งหนี้ (ฝ่ายบัญชี)

ฝ่ายบัญชีเลือกงานจาก **ใบปิดบัญชี** ของพนักงานชิปปิ้งมาออกใบแจ้งหนี้ให้ลูกค้า
ฟอร์มลอกจาก [ชีตต้นฉบับ](https://docs.google.com/spreadsheets/d/11-J91XsudZsK_3_pZwOeR3IaSSaKsvkaX3yoZ15WV3Q/edit)

## 2 role ใหม่

| role | เข้างาน | ออกใบแจ้งหนี้ | อนุมัติ | เห็นใบของใคร |
|---|---|---|---|---|
| `manager-account` | คอม Windows | ✅ | ✅ | ทุกคน |
| `employee-account` | คอม Windows | ✅ | ❌ | เฉพาะที่ตัวเองสร้าง |

ทั้งคู่เข้างานเหมือน `manager` / `employee-office` คือใช้แค่ตำแหน่ง **ไม่ต้องถ่ายรูป**
และเข้าหน้า `admin.html` แต่เห็นแค่ 2 เมนู (เข้างาน + ใบแจ้งหนี้) เมนูอื่นถูกซ่อน

ตั้ง role ให้พนักงานได้ที่ **หน้า admin → พนักงาน**

## ใบ 2 แบบ — ต่างกันที่ "ที่มาของยอด" ไม่ใช่แค่ VAT

นี่คือเหตุผลที่โค้ดต้องแยกสองทาง ไม่ใช่แค่เปิด/ปิดการคิด VAT

| | **V** (มี VAT) | **NV** (ไม่มี VAT) |
|---|---|---|
| ที่มาของยอด | **ใบปิดบัญชี** | **ชีตงานขนส่ง** (คอลัมน์ `แลก DO`) |
| รายการ | ADV - ค่า LIFT ON / LIFT OFF / STORAGE / EXTRA MOVEMENT | ADV - ค่าแลก DO |
| คิดยอด | ต้นทุน **× 1.04** แล้วบวก **VAT 7%** | ใช้ยอดตรง ๆ ไม่บวกอะไร |

ตัวอย่างฝั่ง V: ต้นทุนจากใบปิดบัญชี 1,040 → ×1.04 = **1,081.60** → VAT 7% = **75.71** → รวม **1,157.31**
(1.04 คือค่าบริการที่บวกจากต้นทุนที่สำรองจ่ายไป ไม่ใช่ภาษี — ภาษีคิดทีหลังจากยอดที่บวกแล้ว)

## เลขที่ใบแจ้งหนี้

```
V 202609 01
│    │    └── เลขรัน 2 หลัก
│    └─────── yyyymm
└──────────── V = มี VAT | NV = ไม่มี VAT
```

- **นับแยกกันระหว่าง V กับ NV** — วันเดียวกันมีได้ทั้ง `V20260901` และ `NV20260901`
- **ขึ้นเดือนใหม่รีเซ็ตเป็น 01** เอง (period เปลี่ยนจึงไม่เจอเลขเดิม)
- เลขถูกจอง **ในทรานแซกชันเดียวกับการบันทึก** ถ้าแยกกันแล้วมีคนกดพร้อมกัน 2 คนจะได้เลขเดียวกัน
- เต็มที่เดือนละ 99 ใบต่อประเภท เกินกว่านั้นจะได้ error `seq_overflow` (ถ้าถึงจริงต้องขยายเป็น 3 หลัก)

## วิธีใช้

1. หน้า **ใบแจ้งหนี้ → ออกใบใหม่** — ตารางแสดงงานราย BL จากใบปิดบัญชี
   พร้อมยอดที่คูณ 1.04 ให้แล้ว และป้ายบอกว่า BL ไหนออกใบไปแล้ว (กันออกซ้ำ)
2. กดปุ่ม **V** หรือ **NV** ที่แถวนั้น — ระบบดึงรายการมาให้อัตโนมัติ
3. เติมชื่อ/ที่อยู่/เลขผู้เสียภาษีของลูกค้า **เพิ่ม/ลบ/แก้รายการได้** (กรอกจำนวน × ราคา/หน่วย
   ระบบคูณให้เอง หรือจะใส่จำนวนเงินตรง ๆ ก็ได้)
4. **บันทึกใบแจ้งหนี้** → ได้เลขที่จริง
5. **🖨️ พิมพ์ / PDF** → เปิดหน้าต่างใหม่เป็นฟอร์มตามชีต สั่งพิมพ์หรือ Save as PDF ได้เลย

ใบที่บันทึกแล้วดูได้ที่แท็บย่อย **ใบที่ออกแล้ว** — `manager-account` กดอนุมัติได้ที่นั่น

## เรื่องที่ต้องรู้

**ฝั่ง NV ต้องติดสคริปต์ชีตใหม่ก่อน** — ค่าแลก DO เพิ่งถูกเพิ่มเข้า `transport_jobs.do_fee`
ข้อมูลที่ sync ไว้ก่อนหน้านี้จะเป็น 0 ทั้งหมด ต้องเอา `scripts/TransportSync.gs` ตัวล่าสุด
ไปวางในชีตทั้ง 2 ไฟล์แล้ว Run `setupSync` ใหม่ ยอดฝั่ง NV ถึงจะขึ้น
(ดู [TRANSPORT-SYNC.md](TRANSPORT-SYNC.md))

**ยังไม่มีการหักภาษี ณ ที่จ่าย 3%** — ในชีตต้นฉบับช่องนี้เป็น `-` ระบบจึงตั้งเป็น 0 ไว้
ถ้าต้องใช้จริงต้องเพิ่มช่องกรอกในฟอร์ม (ฐานข้อมูลมีคอลัมน์ `withholding` รออยู่แล้ว)

**ลูกค้ายังต้องกรอกเอง** — ใบปิดบัญชีเก็บแค่ชื่อชิปเปอร์ ไม่มีที่อยู่กับเลขผู้เสียภาษี
ถ้าอยากให้เติมอัตโนมัติต้องทำทะเบียนลูกค้าเพิ่ม

**1 BL หลายตู้รวมเป็นบรรทัดเดียว** — ใบปิดบัญชีแตกเป็นหลายแถวต่อตู้
ระบบรวมยอดของ BL เดียวกันให้เหลือบรรทัดละประเภทค่าใช้จ่าย ตรงกับฟอร์มในชีต
